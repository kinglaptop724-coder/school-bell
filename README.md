# ระบบออดและประกาศเสียงตามสายอัตโนมัติ (PWA ใช้ออฟไลน์ได้)

โรงเรียนอนุบาลชุมชนหนองบัวแดง

## วิธีขึ้น GitHub Pages
1. สร้าง repo แล้วอัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** (ต้องมี `index.html`, `sw.js`, `manifest.webmanifest`, โฟลเดอร์ `vendor/` และ `icons/`)
2. ไปที่ Settings → Pages → Source: Deploy from a branch → เลือก `main` / `(root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## วิธีใช้งานที่เครื่องของโรงเรียน (ครั้งแรก ต้องมีอินเทอร์เน็ต)
1. เปิดลิงก์ด้วย Chrome หรือ Edge รอให้โหลดเสร็จ (ระบบจะแคชทุกไฟล์เก็บไว้ในเครื่อง)
2. แท็บ **คลังเสียง** → **เลือกโฟลเดอร์เสียง** → อนุญาต
3. ติดตั้งเป็นแอป: ไอคอนติดตั้งที่แถบที่อยู่ (หรือเมนู ⋮ → Install)
4. (ถ้าใช้ Gemini) ใส่ API Key ที่ "ตั้งค่าขั้นสูง" แล้วกด "สร้างล่วงหน้า" ตอนมีเน็ต

หลังจากนี้ปิดอินเทอร์เน็ตได้ ระบบยังเปิดและตีออดตามเวลาได้

## ข้อควรระวัง
- ห้ามใส่ Gemini API Key ลงในไฟล์ก่อน push (repo สาธารณะจะทำให้คีย์รั่ว)
- ต้องเปิดผ่าน `https://` (GitHub Pages ได้อยู่แล้ว) หรือ `localhost` ถึงจะใช้ Service Worker ได้ เปิดไฟล์ตรงๆ แบบ `file://` จะไม่แคช
- ต้องใช้ลิงก์เดิม เบราว์เซอร์เดิม โปรไฟล์เดิม ไม่เช่นนั้นจะไม่เห็นไฟล์เสียงที่เก็บไว้
- เปิดหน้าเว็บค้างไว้ และตั้งคอมไม่ให้ Sleep เพื่อให้ออดอัตโนมัติทำงาน

## เมื่อแก้ไขโค้ดแล้วอัปเดตขึ้น GitHub
เปลี่ยนค่า `VERSION` ในไฟล์ `sw.js` เป็นข้อความใหม่ทุกครั้ง (เช่น `'v2'`) เพื่อให้เครื่องที่ใช้งานอยู่ดึงเวอร์ชันใหม่ จะมีผลเมื่อเปิดหน้าใหม่รอบถัดไป

## ไลบรารีที่รวมไว้ (ไม่ต้องใช้ CDN)
- Tailwind CSS 3 (build เป็น `vendor/tailwind.css` แล้ว)
- Font Awesome Free 6 (`vendor/fa/`)
- ฟอนต์ IBM Plex Sans Thai (`vendor/fonts/`)

หากเพิ่มคลาส Tailwind ใหม่ใน `index.html` ต้อง build `vendor/tailwind.css` ใหม่ด้วย (`npx tailwindcss@3 -c tailwind.config.js -i in.css -o vendor/tailwind.css --minify`)
