# ระบบออดและประกาศเสียงตามสายอัตโนมัติ (PWA ใช้ออฟไลน์ได้)

โรงเรียนอนุบาลชุมชนหนองบัวแดง

## วิธีขึ้น GitHub Pages
1. สร้าง repo แล้วอัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** (ต้องมี `index.html`, `sw.js`, `manifest.webmanifest`, โฟลเดอร์ `vendor/` และ `icons/`)
2. ไปที่ Settings → Pages → Source: Deploy from a branch → เลือก `main` / `(root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## วิธีใช้งานที่เครื่องของโรงเรียน (ครั้งแรก ต้องมีอินเทอร์เน็ต)
1. เปิดลิงก์ด้วย Chrome หรือ Edge รอให้โหลดเสร็จ (ระบบจะแคชทุกไฟล์เก็บไว้ในเครื่อง)
2. แท็บ **คลังเสียง** → **เลือกโฟลเดอร์เสียง** → อนุญาต
3. ติดตั้งเป็นแอป: ไอคอนติดตั้งที่แถบที่อยู่ (หรือเมนู ⋮ → Install)
4. (ถ้าใช้ Gemini) ใส่ API Key ที่ "ตั้งค่าขั้นสูง" แล้วกด "สร้างล่วงหน้า" ตอนมีเน็ต

หลังจากนี้ปิดอินเทอร์เน็ตได้ ระบบยังเปิดและตีออดตามเวลาได้

## ข้อควรระวัง
- ห้ามใส่ Gemini API Key ลงในไฟล์ก่อน push (repo สาธารณะจะทำให้คีย์รั่ว)
- ต้องเปิดผ่าน `https://` (GitHub Pages ได้อยู่แล้ว) หรือ `localhost` ถึงจะใช้ Service Worker ได้ เปิดไฟล์ตรงๆ แบบ `file://` จะไม่แคช
- ต้องใช้ลิงก์เดิม เบราว์เซอร์เดิม โปรไฟล์เดิม ไม่เช่นนั้นจะไม่เห็นไฟล์เสียงที่เก็บไว้
- เปิดหน้าเว็บค้างไว้ และตั้งคอมไม่ให้ Sleep เพื่อให้ออดอัตโนมัติทำงาน

## เมื่อแก้ไขโค้ดแล้วอัปเดตขึ้น GitHub
เปลี่ยนค่า `VERSION` ในไฟล์ `sw.js` เป็นข้อความใหม่ทุกครั้ง (เช่น `'v2'`) เพื่อให้เครื่องที่ใช้งานอยู่ดึงเวอร์ชันใหม่ จะมีผลเมื่อเปิดหน้าใหม่รอบถัดไป

## ไลบรารีที่รวมไว้ (ไม่ต้องใช้ CDN)
- Tailwind CSS 3 (build เป็น `vendor/tailwind.css` แล้ว)
- Font Awesome Free 6 (`vendor/fa/`)
- ฟอนต์ IBM Plex Sans Thai (`vendor/fonts/`)

หากเพิ่มคลาส Tailwind ใหม่ใน `index.html` ต้อง build `vendor/tailwind.css` ใหม่ด้วย (`npx tailwindcss@3 -c tailwind.config.js -i in.css -o vendor/tailwind.css --minify`)

## รีโมตสั่งงานลำโพงจากมือถือ (แท็บ "รีโมต")
มือถือส่งคำสั่งผ่าน Google Apps Script (`Code.gs`) แล้วคอมโรงเรียนมารับไปเล่นเสียงเอง สั่งได้ 5 แบบ: ตีออด, เปิดไฟล์ในคลังเสียง, พิมพ์ข้อความให้พูด (TTS), **อัดเสียงบนมือถือแล้วส่งไปประกาศ** (หัวข้อ "ประกาศเสียงตามสายโดยไม่ต้องเดินไปจับไมค์") และหยุดเสียง

**ตั้งค่าครั้งแรก**
1. ใน Apps Script ต้อง deploy `Code.gs` เวอร์ชันล่าสุดที่มี `cmd_send` / `cmd_poll` / `cmd_status` (Deploy → Manage deployments → แก้เป็น New version) และตั้ง `BELL_KEY` ใน Script Properties
2. ทั้งมือถือและคอมโรงเรียน ใส่ "รหัสแจ้งเตือน" ให้ตรงกับ `BELL_KEY` (หน้าประกาศเสียง → ปรับแต่งเสียง → แจ้งเตือนบนมือถือ) ค่าเริ่มต้นคือ `cbd`
3. **ตั้งรหัสคอมโรงเรียน (PC_KEY):** ใน Apps Script → Project Settings → Script Properties เพิ่มชื่อ `PC_KEY` ค่า = รหัสที่ตั้งเอง (คนละตัวกับ `BELL_KEY`) แล้ว deploy เวอร์ชันใหม่
4. **บนคอมโรงเรียน:** แท็บ รีโมต → ปุ่ม "คอม" → ใส่รหัสคอมโรงเรียนครั้งแรก (เครื่องจะจำไว้) → เปิดสวิตช์ "รับคำสั่งจากมือถือ" แล้วเปิดหน้าเว็บค้างไว้
   - เครื่องที่ไม่ได้ใส่รหัสนี้ จะเลือกเป็นคอมโรงเรียนไม่ได้ และเซิร์ฟเวอร์จะไม่ให้รับคำสั่ง/โหลดเสียงด้วย (กันคนเปิดเว็บเล่นแล้วระบบรวน)
   - ค่าเริ่มต้นของทุกเครื่องคือ "มือถือ" เสมอ
   - ใส่รหัสผิด 5 ครั้ง จะถูกล็อก 10 นาที
   - เปลี่ยนรหัสได้โดยแก้ `PC_KEY` ใน Script Properties คอมโรงเรียนจะหยุดรับคำสั่งและต้องใส่รหัสใหม่
   - กดปุ่ม "เลิกใช้เครื่องนี้เป็นคอมโรงเรียน" ในโหมดคอม เพื่อถอนสิทธิ์เครื่องนั้น
5. **บนมือถือ:** แท็บ รีโมต → "เครื่องนี้คือมือถือ" จะเห็นสถานะคอมออนไลน์/ออฟไลน์ และปุ่มสั่งงาน

**ข้อควรรู้**
- เสียงออกที่ลำโพงของคอมโรงเรียนเท่านั้น
- อัดเสียงบนมือถือได้ครั้งละไม่เกินประมาณ 25 วินาที (ไม่ใช่การพูดสด: อัดจบ กดหยุด แล้วจึงส่งไปเล่นที่คอม ใช้เวลาประมาณ 5-10 วินาที) ไฟล์เสียงเก็บบน Apps Script ชั่วคราว 10 นาที
- คอมถามหาคำสั่งทุก 4 วินาที คำสั่งที่เก่ากว่า 90 วินาทีจะถูกข้าม และเมื่อเปิดหน้าใหม่ จะไม่เล่นคำสั่งค้างเก่า
- คอมต้องไม่ Sleep และไม่ควรย่อหน้าต่างไว้นานๆ เพราะเบราว์เซอร์จะชะลอแท็บที่ถูกซ่อน
- เบราว์เซอร์ต้องเคยมีการคลิก/แตะในหน้านี้อย่างน้อย 1 ครั้งหลังเปิด จึงจะเล่นเสียงได้ (ข้อจำกัด autoplay)
- มือถือจะถามยืนยันก่อนส่งคำสั่งทุกครั้ง (ยกเว้นปุ่มหยุดเสียง)

## ระบบรหัสผ่านเข้าใช้งาน
- เปิดหน้าเว็บครั้งแรกจะให้ **ตั้งรหัสผ่าน** หลังจากนั้นทุกครั้งที่เปิดหน้าเว็บจะถามรหัสก่อน
- ปุ่ม **ล็อก** ที่มุมขวาบนใช้ล็อกหน้าจอได้ทันที และระบบล็อกให้เองเมื่อไม่มีการใช้งาน 10 นาที (แก้ได้ที่ `AUTO_LOCK_MIN` ใน `index.html`)
- ตอนล็อกอยู่ **ออดอัตโนมัติยังทำงานตามเวลาปกติ** และกล่อง ON AIR พร้อมปุ่มหยุดเล่นยังมองเห็นอยู่
- เปลี่ยนรหัสได้ที่หน้าใส่รหัส กด "เปลี่ยนรหัสผ่าน" (ต้องใส่รหัสเดิม)
- ใส่รหัสผิด 5 ครั้งติดกัน ต้องรอ 30 วินาที
- **ลืมรหัสผ่าน:** เปิดหน้าเว็บ กด F12 → แท็บ Console → พิมพ์ `localStorage.removeItem('nongbuadaeng_lock_v1')` แล้วกด Enter จากนั้นรีโหลดหน้า จะตั้งรหัสใหม่ได้ (ไฟล์เสียงในคลังไม่หาย)
- รหัสผ่านเก็บเฉพาะในเบราว์เซอร์เครื่องนั้น (เข้ารหัสแบบแฮช) ไม่ได้ส่งขึ้นอินเทอร์เน็ต
- **ข้อจำกัด:** นี่เป็นการล็อกกันคนทั่วไปใช้งานโดยไม่ได้ตั้งใจ ไม่ใช่ระบบความปลอดภัยระดับสูง เพราะเว็บนี้ทำงานในเครื่องทั้งหมด คนที่มีความรู้ด้านเทคนิคและนั่งอยู่หน้าเครื่องสามารถข้ามได้ ควรล็อกหน้าจอ Windows ร่วมด้วย
